# 首页

星域世界创立于 **2018 年 8 月 14 日**，是一个 Minecraft 国际版服务器。服务器以长期运行为目标，通常情况下会持续开放 Mod 服务器，欢迎你邀请朋友一同加入。

你可以在服务器内自由游玩，可以在玩家交流群内讨论其他游戏或话题，即使暂时不游玩服务器，也欢迎正常交流。

若你在游玩过程中遇到问题或对服务器有建议，欢迎反馈，我们会认真对待每一条合理的意见。

星域世界是一个**长期运行、持续维护的服务器项目**。周目会不断更替，玩法会不断变化，但服务器本身长期存在。

我们相信，Minecraft 的乐趣不只来自“保存结果”，也来自一次次新的开始、不同方向的尝试，以及每一周目独特的体验。

我们坚持：

- 每个周目都会引入新的玩法方向，保持活力
- 运维以稳定、可持续为第一目标
- 不做快餐服，长期开服，不跑路
